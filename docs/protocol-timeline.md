# Эволюция протоколов аутентификации

| Период | Технология | Значение |
|---|---|---|
| 1983 | Kerberos (Project Athena, MIT) | Симметричная криптография, доверенная третья сторона (KDC), SSO через «билеты» |
| 1996 | HTTP Basic Auth (RFC 1945) | Base64-передача логина/пароля, без конфиденциальности без TLS |
| 1999 | HTTP Digest Auth (RFC 2617) | Challenge-response поверх хеширования, ограниченное распространение |
| 2002–2005 | SAML 1.0 → 2.0 | XML-федерация, «золотой стандарт» Enterprise SSO |
| 2006 | Amazon S3 (API keys, HMAC) | Массовое распространение подписи запросов для сервис-клиентов |
| 2012 | OAuth 2.0 (RFC 6749) | Делегированный доступ без передачи пароля приложению |
| 2014 | OpenID Connect 1.0 | Слой идентификации поверх OAuth 2.0, JWT |
| 2014 | FIDO U2F 1.0 | Первый стандарт аппаратной двухфакторной аутентификации |
| 2015 | JWT (RFC 7519) | Компактный JSON-носитель claims, вытеснение XML-токенов |
| 2019 | W3C WebAuthn | Нативная поддержка беспарольного входа в браузерах |
| 2020 | NIST SP 800-207 (Zero Trust) | Каждый запрос — потенциально недоверенный, непрерывная проверка |
| 2022–2024 | Passkeys, DID v1.0 | Синхронизируемые ключи, децентрализованные идентификаторы |

Хронология показывает общее направление: от доверия статическому секрету —
к криптографической привязке аутентификации к конкретному устройству и
домену, и от разового входа — к непрерывной проверке каждого запроса.
